# Scientific Background

## Targeted Memory Reactivation

Targeted Memory Reactivation (TMR) is a research area in which memory-related cues are associated with learning and presented under defined experimental conditions to study memory effects. TMR findings are sensitive to sleep measurement, cue timing, cue identity, participants, and task design.

This repository's current implementation is not evidence of TMR efficacy.

## Scope of this repository

The existing demo provides:

- structured educational content;
- deterministic acoustic markers;
- synthetic session metadata;
- cue-association records;
- illustrative simulated timelines.

These are software demonstrations. They are not EEG data, clinical sleep staging, or evidence of cue delivery during sleep.

## Open questions

- What speech properties, if any, should serve as cue candidates?
- How should timing metadata be validated against generated audio?
- What educational outcome measures are appropriate and culturally fair?
- How should synthetic and participant data remain distinguishable?
- What evidence would justify future hardware or stimulation integration?

## Interpretive safeguards

Future findings require preregistration, suitable control conditions, validated measurements, appropriate statistical analysis, and qualified ethical review. Absence of an EEG implementation must not be compensated for with assumptions about sleep state.
